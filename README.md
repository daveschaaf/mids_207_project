# MIDS 207 Final Project
Ben Wang, Karim Mattar, David Schaaf

Spring 2026 Final Project for MIDS 207 Applied Machine Learning

## Overview
This project builds a product recommendation system for H&M using purchase prediction models trained on customer transaction data. We frame recommendation as a binary classification problem: given a customer-product pair, will the customer purchase?

## Notebooks
Run in order. Each notebook saves outputs (cleaned data, features, models) that are loaded by subsequent notebooks.

| Notebook | Description |
|---|---|
| `01_eda_cleaning.ipynb` | Exploratory data analysis and data cleaning |
| `02_repeat_customer_analysis.ipynb` | Repeat customer behavioral analysis |
| `03_customer_clustering.ipynb` | K-means customer segmentation |
| `04_feature_engineering.ipynb` | Feature engineering and dataset construction |
| `05_purchase_prediction_nn.ipynb` | Purchase prediction — neural network |
| `06_purchase_prediction_df.ipynb` | Purchase prediction — decision forest models |
| `07_product_recommendation.ipynb` | Product recommendation engine |

## Data
Raw and processed data lives in `data/`. Processed files are generated by running the notebooks in order and are not included in the repository.
